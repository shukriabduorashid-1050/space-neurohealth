ENVIRONMENT INDEX

Transparent Composite Scoring

The Environment Index is an interface-level demonstration score. Each environmental variable is normalized against a reference range and assigned a predefined weight.

Formula concept: Index = Σ(weight × normalized deviation). The implementation bounds each component between 0 and 100 before calculating the weighted score.

PVT METRICS

Reaction-Time Measures

Reaction Time

Raw response latency measured in milliseconds.

RRT

Reciprocal Reaction Time = 1000 / RT when RT is expressed in milliseconds.

Lapse

This prototype counts responses above 500 ms as lapses.

False Start

Responses below 150 ms are treated as anticipatory responses in this prototype.

TIME-LAGGED CORRELATION

Pearson Correlation

The dashboard can shift the environmental series relative to the performance series by 0–4 data intervals to demonstrate lagged association.

The resulting Pearson coefficient describes the linear association in the paired observations. It does not prove that an environmental condition caused a change in human performance.

RESEARCH PROTOTYPE
🛰

A human-performance monitoring concept

Space NeuroHealth explores how environmental monitoring and cognitive-performance testing could be brought together into one accessible analytical interface.

The prototype is designed to make the distinction between measured data, synthetic demonstration data and analytical interpretation visible to the user.
